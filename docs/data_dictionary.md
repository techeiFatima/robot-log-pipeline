# Data dictionary

Generated by `python -m robot_pipeline.data_dictionary` from the dbt docs and the
database; do not edit by hand. The data is the public UR3 CobotOps dataset (UCI),
standing in for real robot logs. Times are UTC. `␠` marks a trailing space.

## Loader tables (`cobot.duckdb`)

### `raw_logs`

*cobot.duckdb.* The source file exactly as delivered, plus two loader columns.

| Column | Type | Meaning |
|---|---|---|
| `Num` | BIGINT | Row counter within the file, 1-based. |
| `Timestamp` | VARCHAR | Log time as text, ISO 8601 ending in "Z" (UTC); 863 values wrapped in stray quotes. |
| `Current_J0` | DOUBLE | Joint 0 current (can be negative; unconfirmed meaning). |
| `Temperature_T0` | DOUBLE | Temperature, probably joint 0 (breaks the Temperature_J1..J5 naming; unconfirmed). |
| `Current_J1` | DOUBLE | Joint 1 current (can be negative; unconfirmed meaning). |
| `Temperature_J1` | DOUBLE | Joint 1 temperature. |
| `Current_J2` | DOUBLE | Joint 2 current (can be negative; unconfirmed meaning). |
| `Temperature_J2` | DOUBLE | Joint 2 temperature. |
| `Current_J3` | DOUBLE | Joint 3 current (can be negative; unconfirmed meaning). |
| `Temperature_J3` | DOUBLE | Joint 3 temperature. |
| `Current_J4` | DOUBLE | Joint 4 current (can be negative; unconfirmed meaning). |
| `Temperature_J4` | DOUBLE | Joint 4 temperature. |
| `Current_J5` | DOUBLE | Joint 5 current (can be negative; unconfirmed meaning). |
| `Temperature_J5` | DOUBLE | Joint 5 temperature. |
| `Speed_J0` | DOUBLE | Joint 0 speed (can be negative; unconfirmed meaning). |
| `Speed_J1` | DOUBLE | Joint 1 speed (can be negative; unconfirmed meaning). |
| `Speed_J2` | DOUBLE | Joint 2 speed (can be negative; unconfirmed meaning). |
| `Speed_J3` | DOUBLE | Joint 3 speed (can be negative; unconfirmed meaning). |
| `Speed_J4` | DOUBLE | Joint 4 speed (can be negative; unconfirmed meaning). |
| `Speed_J5` | DOUBLE | Joint 5 speed (can be negative; unconfirmed meaning). |
| `Tool_current` | DOUBLE | Tool (gripper) current. |

| `Robot_ProtectiveStop` | DOUBLE | 1 = robot stopped itself for safety, 0 = no stop, empty = unknown (54 rows). |
| `grip_lost` | BOOLEAN | True when the gripper lost its grip. |
| `source_file` | VARCHAR | Added by the loader: name of the file the row came from. |
| `loaded_at` | TIMESTAMP WITH TIME ZONE | Added by the loader: when the row was stored (UTC). |

### `load_audit`

*cobot.duckdb.* One row per file per loader run.

| Column | Type | Meaning |
|---|---|---|
| `source_file` | VARCHAR | File name. |
| `sha256` | VARCHAR | Checksum of the file's bytes. |
| `rows_loaded` | BIGINT | Rows of this file in raw_logs after the run. |
| `rows_replaced` | BIGINT | Rows deleted and re-inserted for this file in this run. |
| `loaded_at` | TIMESTAMP WITH TIME ZONE | Time of the run (UTC). |
| `action` | VARCHAR | loaded (new file), replaced (changed content), reloaded (same content rewritten, e.g. --force), unchanged (skipped). Only loaded/replaced count as new data. |

## dbt models (`cobot.duckdb`)

### `stg_robot_logs`

*staging view.* One clean row per raw log row (no rows dropped). Types fixed, names in snake_case, stray quotes removed from timestamps. Rows with no stop value are kept and flagged with stop_status = 'unknown'.

| `row_num` | BIGINT | The source's "Num" column, a 1-based row counter within the file. |
| `timestamp_raw` | VARCHAR | The source "Timestamp" text exactly as delivered, quotes included. |
| `had_stray_quotes` | BOOLEAN | True when timestamp_raw was wrapped in double quotes (finding 2). |
| `event_ts` | TIMESTAMP | When the robot logged the row, as a TIMESTAMP in UTC (source values end in "Z"). |
| `current_j0` | DOUBLE | Joint 0 current, as delivered. Can be negative (meaning unconfirmed, finding 9). |
| `current_j1` | DOUBLE | Joint 1 current, as delivered. |
| `current_j2` | DOUBLE | Joint 2 current, as delivered. |

| `temperature_j2` | DOUBLE | Joint 2 temperature, as delivered. |
| `temperature_j3` | DOUBLE | Joint 3 temperature, as delivered. |
| `temperature_j4` | DOUBLE | Joint 4 temperature, as delivered. |
| `temperature_j5` | DOUBLE | Joint 5 temperature, as delivered. |

### `fct_stop_events`

*marts table.* One row per protective-stop episode (a run of consecutive rows marked as a stop, broken by any non-stop row, unknown row, or recording gap).

| Column | Type | Meaning |
|---|---|---|
| `stop_event_id` | VARCHAR | Episode key. |
| `source_file` | VARCHAR | Name of the Excel file the row was loaded from. |
| `started_at` | TIMESTAMP | event_ts of the first stop row (UTC). |
| `ended_at` | TIMESTAMP | event_ts of the last stop row (UTC). |
| `started_hour` | TIMESTAMP | started_at truncated to the hour. |
| `cycle_id_at_start` | BIGINT | Cycle number on the first stop row. |
| `stop_rows` | BIGINT | Number of log rows in the episode. |
| `duration_seconds` | DOUBLE | ended_at minus started_at; 0 for a one-row episode. |
| `first_row_num` | BIGINT | row_num of the first stop row. |
| `last_row_num` | BIGINT | row_num of the last stop row. |
| `grip_lost_during_stop` | BOOLEAN | True if any row in the episode had grip_lost. |
| `avg_joint_temperature` | DOUBLE | Mean over the episode of the per-row average of the six joint temperatures. |
| `max_joint_temperature` | DOUBLE | Highest single joint temperature seen during the episode. |
| `avg_total_abs_current` | DOUBLE | Mean over the episode of the sum of absolute joint currents. |
| `avg_total_abs_speed` | DOUBLE | Mean over the episode of the sum of absolute joint speeds. |
| `avg_tool_current` | DOUBLE | Mean tool current during the episode. |
| `seconds_since_previous_stop` | DOUBLE | Seconds from the previous episode's end to this one's start; NULL for the first. |

## Stream tables (`stream.duckdb`, written by the Kafka consumer; simulation)

| Table | One row per | Key columns |
|---|---|---|
| `stream_events` | event stored once | `event_id` (PK, "<file>:<Num>"), `event_ts` (naive UTC), `protective_stop`, `payload` (JSON of the 24 raw columns), `received_at`, `is_out_of_order`, `is_late`, `lateness_seconds`, `kafka_topic/partition/offset` |
| `stream_duplicates` | repeated delivery that was ignored | `event_id`, `received_at`, Kafka coordinates (unique) |
| `stream_rejects` | message that was not a valid event | `reason`, `raw_message` (first 2,000 chars), Kafka coordinates (unique) |
| `stop_alerts_sent` | protective-stop alert sent | `event_id` (PK), `robot_id`, `event_ts`, `alerted_at` |
